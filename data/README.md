# data/

## opcodes.json

Vendored copy of the Game Boy opcode table from gbdev.io:
https://gbdev.io/gb-opcodes/Opcodes.json

Fetched 2026-11-06. 256 unprefixed + 256 CB-prefixed entries
(mnemonic, bytes, cycles, operands, immediate, flags). To refresh,
re-download the file from the link above — there is no build-time fetch.
